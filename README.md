# Calibre Vernier – Medida de una Esfera

**Autor:** F. Lloret  
**Institución:** Dept. of Applied Physics, University of Cadiz  
**ORCID:** https://orcid.org/0000-0002-6506-4027  
**Licencia:** CC BY 4.0 – https://creativecommons.org/licenses/by/4.0/

Laboratorio virtual para medir el diámetro de una esfera con un pie de rey (calibre vernier) 
de precisión 0,05 mm. Incluye tratamiento estadístico de cinco medidas repetidas, 
incertidumbre combinada y propagación de errores en el volumen.
